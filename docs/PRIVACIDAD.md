# Privacidad

Marco Editor procesa el contenido de fotos y vídeos en la memoria del dispositivo. No incorpora una función para subir archivos al servidor, registro de usuarios, analítica ni anuncios.

La web solicita HTML, JavaScript, estilos, iconos y el motor de vídeo al mismo alojamiento. Este puede registrar datos técnicos ordinarios de acceso, como IP y agente de usuario. Los enlaces externos de ayuda, código y descargas se abren solo por decisión del usuario. La aplicación de escritorio restringe las peticiones del contenido a su servidor local. El APK incluye todos los recursos.

El service worker guarda recursos del programa para su uso sin conexión. No almacena los archivos seleccionados, la edición ni los resultados. El navegador y el sistema pueden conservar sus propios datos, historiales y descargas. Al cerrar o recargar la sesión se pierde la edición no descargada.

Android escribe en la caché privada las copias que decides compartir. Se pueden eliminar desde Ajustes de Android → Aplicaciones → Marco Editor → Almacenamiento → Borrar caché. No se hace una copia de seguridad automática de esos datos. La aplicación de destino elegida para compartir aplica sus propias políticas. Cancelar el menú para compartir no guarda el archivo fuera de esa caché.

Las fotos generadas no copian EXIF, incluida la localización GPS. El vídeo elimina los metadatos de origen y conserva solo la primera pista visual y, si corresponde, la primera pista de audio. Los píxeles y el sonido pueden seguir conteniendo información personal. El programa no intenta anonimizar el contenido.

No publiques muestras privadas en incidencias. La fuente de la aplicación y los paquetes son públicos; tus archivos no forman parte de ellos.
