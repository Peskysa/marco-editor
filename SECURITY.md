# Seguridad

No publiques archivos personales, claves o credenciales al comunicar una incidencia. Para vulnerabilidades, utiliza los avisos privados de seguridad de GitHub cuando estén habilitados. Si no lo están, abre una incidencia sin datos sensibles solicitando un canal para comunicar el detalle.

El editor procesa archivos en memoria; los componentes multimedia y el navegador deben mantenerse actualizados. La aplicación de escritorio utiliza aislamiento de contexto, sandbox y un servidor de solo lectura en 127.0.0.1. El contenido no tiene acceso a Node. Android usa el selector del sistema y comparte únicamente la copia elegida.

Los paquetes carecen de firma comercial Windows. Verifica la procedencia y las sumas. Las sumas no garantizan por sí solas que un archivo sea seguro. La firma estable Android permite comprobar la continuidad de las actualizaciones.
